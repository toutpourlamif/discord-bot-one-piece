# Univers narratif

Règles narratives valables pour **toute** l'histoire du jeu, tous arcs/îles confondus. Les documents par île/arc (`docs/domains/event/<île>-mainstory.md`) s'appuient dessus sans les répéter.

## Le protagoniste

Le protagoniste de l'histoire est **le capitaine du joueur**, c'est lui qui vit les événements canons attribués à Luffy (rencontres, combats, décisions). Les autres personnages canon (Zoro, Nami, Koby, etc.) gardent leur rôle et leur personnalité.

## Convention de documentation

Chaque île/arc avec une trame narrative a son propre document sous `docs/domains/event/<île>-mainstory.md`. Ces documents restent **purement narratifs** : trame, quêtes annexes, choix, contenu répétable, easter eggs.

## Fils rouges

Intrigues qui traversent plusieurs arcs — à ne pas enterrer dans le document d'une seule île.

### B-17

Le conteur qui narre l'histoire de Gold Roger au tout début du jeu (arc Dawn, cf `apps/bot/src/domains/onboarding/notes.md`) n'est pas ce qu'il semble être.

C'est le plot twist du jeu : ce personnage qui nous a lancé sur notre aventure le fait par intérêt. Il va nous trahir à la fin c'est l'un des antagonistes principales.
Note : B-17 est un nom temporaire jsp encore quoi mettre
